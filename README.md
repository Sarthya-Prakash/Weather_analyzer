# 🌦️ Weather Analyzer

A data analysis project that explores weather datasets to extract meaningful insights using **Pandas, Seaborn, Matplotlib**, and an interactive **Streamlit dashboard**.

---

## 🚀 Overview

This project focuses on:
- Cleaning and preprocessing weather data  
- Performing exploratory data analysis (EDA)  
- Applying feature engineering techniques  
- Visualizing trends and patterns  
- Building an interactive dashboard for better data understanding  

---

## 🛠️ Tech Stack

- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Streamlit  

---

## 📊 Features

- Data cleaning and preprocessing  
- Feature engineering for improved insights  
- Visualization of temperature trends and patterns  
- Interactive dashboard using Streamlit  
- User-friendly data exploration  

---

## ▶️ Run Locally

```bash
git clone https://github.com/Sarthya-Prakash/Weather_analyzer.git
cd Weather_analyzer
pip install -r requirements.txt
streamlit run app.py
```
